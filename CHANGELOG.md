# Changelog — CSA Contributor License Agreements

Notable changes to the CLAs tracked in this ledger, by project. Every version
is frozen, unedited, under that project's `versions/` directory. A signature
binds to the version in force when it was made; prior signatures are never
migrated to a later version.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

- **Security Controls Catalog — CLA v1.0** — frozen as
  `security-controls-catalog/versions/CLA-v1.0.md` (a verbatim copy of the
  in-force CLA). Until a signature references it, it may still be corrected;
  once signed, it is permanent (see that project's `versions/README.md`).
  Becomes a dated release entry below at the first tagged release.
