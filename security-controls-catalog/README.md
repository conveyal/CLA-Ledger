# CLA — Security Controls Catalog

This directory is the **Contributor License Agreement and signature ledger for
the CSA Security Controls Catalog** — the project at
[CloudSecurityAlliance/SecurityControlsCatalog](https://github.com/CloudSecurityAlliance/SecurityControlsCatalog).

Anyone contributing to the Security Controls Catalog signs this CLA once, before
their contributions are accepted. Coverage is **per project**: a signature here
covers the Security Controls Catalog only — other CSA projects have their own
directories and CLAs elsewhere in this ledger (see the
[ledger README](../README.md)).

## What's here

- **[`CLA.md`](CLA.md)** — the current Contributor License Agreement for this project.
- **[`versions/`](versions/)** — frozen, immutable copies of each CLA version
  (current: [`CLA-v1.0.md`](versions/CLA-v1.0.md)). A signature is assent to the
  exact text of a specific version.
- **[`signatures/`](signatures/)** — one signature file per contributor
  (`<numeric-account-id>.md`), each embedding the full CLA text they agreed to.

## How to sign

Open a pull request adding `signatures/<your-numeric-id>.md` — the full text of
[`versions/CLA-v1.0.md`](versions/CLA-v1.0.md) followed by a short signature
block agreeing to it. An automated check validates the file; a maintainer
reviews and merges to accept. **Step-by-step and the block template:
[`signatures/README.md`](signatures/README.md).**

For what signing means and what is recorded, see the
[FAQ](../FAQ.md) and the [privacy note](../PRIVACY.md).
