# Projects tracked in this ledger

Each CSA project that uses this ledger has its **own directory** here,
containing that project's Contributor License Agreement, its frozen CLA
versions, and the signatures of its contributors. **Coverage is per project:** a
contributor signs the CLA for each project they contribute to, so signing
records an explicit agreement to contribute to *that* project.

| Project | Ledger directory | Repository |
|---|---|---|
| Security Controls Catalog | [`security-controls-catalog/`](security-controls-catalog/) | `CloudSecurityAlliance/SecurityControlsCatalog` |

_Future CSA projects (e.g. CCM, AICM) are added as sibling directories when they
adopt this contribution workflow, each with its own CLA and signature set._

> Whether a contributor is covered for a given project is determined by the
> presence of their signature file in that project's `signatures/` directory —
> not by this table, which is a convenience index.
